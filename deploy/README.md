# Подготовка сервера

Текущий этап запускает PostgreSQL и инструменты импорта, но не Telegram-бота.
Проверено на Ubuntu 24.04 x86_64. Для первого пользователя достаточно 1 CPU / 2 ГБ RAM.
Модели работают через внешнее API. Приложение и база ограничены по памяти.

1. Передайте `bootstrap.sh` и публичный SSH-ключ на новый сервер.
2. От root запустите `bash bootstrap.sh /path/to/public-key.pub`.
   Скрипт устанавливает Docker из официального APT-репозитория, создаёт пользователя
   `trainer` и включает UFW. Открыты SSH, HTTP/HTTPS и существующая панель на 1500/1501.
   Существующие правила UFW сохраняются. Пароль root и текущий доступ не меняются. Docker-порты могут обходить UFW;
   поэтому у PostgreSQL намеренно отсутствует публикация портов.
3. Проверьте отдельное SSH-подключение как `trainer`. Доступ к Docker даёт пользователю
   административные возможности; ключ должен оставаться у владельца сервера.
4. От `trainer` скопируйте/клонируйте код в `/opt/training-bot` и выполните:

```sh
cd /opt/training-bot
python3 deploy/create_server_env.py
docker compose --env-file .env.server up -d --wait db
docker compose --env-file .env.server build tools
docker compose --env-file .env.server run --rm tools init
docker compose --env-file .env.server run --rm tools status
```

Пароль базы генерируется на сервере. Файл `.env.server` не включается в Git или Docker image.
Не запускайте `docker compose config` без `--quiet` в публичных логах: вывод содержит
подставленные секреты. Данные сохраняются в именованном Docker volume при перезапуске.
Не используйте `docker compose down -v`: это удалит базу.

## Перед запуском бота

- Импортировать личную историю отдельно от репозитория.
- Проверить Telegram и OpenAI, настроить ID владельца и обработчик бота.
- Настроить отдельную роль PostgreSQL для приложения с ограниченными правами.
- Настроить резервные копии вне сервера и проверить восстановление.
- Проверить автозапуск и восстановление соединений после перезапуска БД.

Перезапуск Docker вместе с системой включён; контейнер базы имеет `restart: unless-stopped`.
Приложение находится на этапе разработки и пока запускается только как CLI-инструмент.
